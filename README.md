## Como rodar o projeto localmente

- Instale o Node.js na versão 18.x ou superior;
- npm install;
- npm run dev

## Tecnologias Utilizadas

A aplicação foi desenvolvida utilizando as seguintes tecnologias e bibliotecas no ecossistema do React:

- Next.js 16+: Framework React para renderização, layouts aninhados e grupos de rotas.
- React 19+: Biblioteca base para a construção da interface do usuário baseada em componentes reutilizáveis.
- TypeScript: Tipagem estática para garantia de segurança e definição das interfaces de dados.
- Tailwind CSS: Framework de CSS focado em classes utilitárias para estilização rápida e responsiva.
- shadcn/ui: Biblioteca de componentes de interface altamente acessíveis e customizáveis.
- Lucide Icons: Coleção de ícones em formato vetorial (SVG) para o menu lateral (Sidebar) e ações do sistema.
